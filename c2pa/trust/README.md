# C2PA trust lists

`C2PA-TRUST-LIST.pem` (claim-signing certificate authorities) and `C2PA-TSA-TRUST-LIST.pem` (timestamp authorities) are copies of the official lists from the C2PA Conformance Program:
https://github.com/c2pa-org/conformance-public/tree/main/trust-list

Downloaded: 23 November 2026. Licence: Creative Commons Attribution 4.0 International (see `LICENSE-CC-BY-4.0.txt`), © Coalition for Content Provenance and Authenticity.

**Refresh these files on every update**, because authorities are added and removed. AI Asli bundles them so it can check signers without contacting any server.
